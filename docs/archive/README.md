# Project archive

This directory preserves superseded plans, completed briefs, and stale
operational snapshots. These files explain how the project reached its current
state, but they are not live instructions.

Current operational sources remain at the repository root:

- `CLAUDE.md` owns working conventions.
- `DESIGN.md` owns visual direction.
- `MAP.md` owns repository navigation.
- `STATUS.md` records chronological project history.
- `BACKLOG.md` owns the small, triaged local queue.

## Archived plans and snapshots

- `BACKLOG-2026-09-07.md`: the former mixed backlog before triage.
- `plans/CODEX_BRIEF.md`: completed storefront and workshop cleanup brief.
- `plans/CODEX_HUMAN_PASS.md`: superseded humanizing audit and early brief.
- `plans/DESIGN_DIRECTIONS.md`: landing directions considered but not selected.
- `plans/NEXT_SESSION.md`: obsolete cold-start handoff.
- `plans/PLAN.md`: dated roadmap whose early phases and ordering are stale.
- `plans/UPLOAD_PHASE23_BRIEF.md`: completed upload implementation handoff.
- `plans/UPLOAD_UI_PLAN.md`: completed upload UI design plan.
- `tools/post-backlog-to-issues.ps1`: superseded PowerShell issue importer.

Archived files are preserved as written. They may contain constraints, paths,
or proposed work that no longer apply.
