# Niche developer and program scout, 2026-10-21

Research findings, not accepted decisions. No installation or site implementation.
The request combines two interests: useful niche software from individual makers,
and memorable websites like Manraj Singh's. Potential below is an editorial
judgment about the idea and visible work, not a prediction of commercial success.

## Anchors recovered from the supplied context

Read the signed-in LinkedIn feed through Chrome's extension. It contained Shane
Benlolo's Hypersphere launch post. An existing adjacent tab held Tartan. The feed
is dynamic, so this records what was visible during the inspection, not every
post the user may have meant. Performance figures in the post are author claims;
none were benchmarked here.

- [Manraj Singh](https://manraj.me/): NoStep, Tartan, Promptbox and Soundalike.
  Live desktop inspected, including its particle-name hero, project controls,
  radio and discovery counter. NoStep's doorway control connects a visual action
  to the project's actual measurement problem. Tartan keeps semester information
  as local files. See the separate existing Manraj study for prior proposals.
- [Hypersphere](https://hypersphere.systems/): specialist mission analysis,
  including passes, coverage, communications and close approaches. Live landing
  inspected: Earth-at-sunset imagery, orbit geometry and compact mission readouts
  make the product legible. It offers early access and a showcase. Numerical
  accuracy and the site's stated validation checks were not independently tested.

## What matters for MYTHCORP

- F1: Manraj and Sonner demonstrate a project's claim through an action. A
  meaningful control is more useful than adding unrelated visual effects.
- F2: ryOS is the strongest source here for an authored place with consistent
  interaction rules. The full desktop metaphor would be a separate design choice,
  not a recommendation to replace MYTHCORP's current rooms.
- F3: Hypersphere ties visual atmosphere to specialist content. The orbital
  geometry and mission readouts are relevant to the software it sells.

Start with P1 for smaller-program discovery, P2 for web play, and P4 for deep
specialist software. P5 and P6 are established craft references. This shortlist
does not rank developers' overall ability or establish commercial traction.

Checked public primary sources and the signed-in feed on 2026-10-21. Live desktop
