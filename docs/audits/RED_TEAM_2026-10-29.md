# Red-team pass, 2026-10-29

Type: AUDIT. Audience: HUMAN + AGENT. Findings, not accepted decisions. No code,
config or deployment changed.

Scope: source review of the public attack surface (middleware and site lock,
`/api/upload`, `/api/delete`, `/api/img`, `/api/sky`, `src/lib/upload/*`),
passive GETs and HEADs against mythcorp.org and i.mythcorp.org, public DNS and
whois for mythcorp.com, and `npm audit --omit=dev`. No authenticated requests,
uploads, delete attempts, fuzzing or load testing. Also red-teams the landing
and AI-age ideas proposed the same day.

## What already holds up

Upload keys (192-bit) and delete tokens (128-bit) are random and stored hashed.
The key is checked before the body is read. File type comes from magic bytes,
the served content type comes from the allowlist, `nosniff` is set and images
live on a separate host. Object keys are shape-validated before they reach the
S3 path. Delete is POST-only and answers the same for a wrong token and a
deleted image. `/api/sky` never returns or logs coordinates.

## Proposed ideas, red-teamed

- Agent data (terrarium, `agents` command, AGENTS readout): receipts reveal private repo names, local paths and a 3 a.m. work pattern. Publish only nicknames, actions and results, round times coarsely and delay publication.
- `sniff` paste box: render highlights as text nodes, never HTML; keep it client-side with no logging.
- Hallucinated 404 and `hallucinate`: put the fiction label inside the visual frame so a screenshot carries it.
- Any live model (guard, Gandalf): prompt injection, cost abuse and jailbreak screenshots under Weibao's name. Keep these scripted.
- OPERATOR name row: links the real name to the domain. LinkedIn already does this, so it is a conscious choice rather than a leak.

## Home page design, red-teamed

Live desktop and phone views plus the accessibility tree, 2026-10-29. Opinions
about failure modes, not measurements; contrast and load timing were not
measured (the browser pane was hidden, which can throttle pages).
